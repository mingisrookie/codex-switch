# 可选技能说明

ChatGPT Switch 的“技能”页面可管理 **Image2** 和 **Grok 搜索**。这些是可选扩展，不是使用官方模式或 API 模式的前置条件。

## 核心原则

- 不安装任何技能，模式切换、会话管理、备份、诊断和更新仍可正常使用。
- 技能由应用显示其安装状态、服务 URL 和“是否已加密配置”的状态；不会在页面中显示已保存的 API Key。
- 安装或更新技能前，应用会要求相关 Codex 写入程序处于可安全处理的状态。
- 如果应用发现现有目录，覆盖安装会先创建备份；不要手动删除未知目录来绕过检查。

## Image2

Image2 用于图像生成或编辑。它需要单独配置服务 URL 和 API Key，且与 ChatGPT Switch 的模式切换无关。

配置后，请在你有权使用的服务与模型范围内调用。不要在公开问题报告中提供其 Key、请求内容或生成记录。

## Grok 搜索

Grok 搜索用于互联网与 X 内容检索。它也需要独立配置服务 URL 和 API Key，与官方模式/API 模式无依赖关系。

搜索结果和外部服务的准确性、费用、数据处理规则由对应服务决定；使用时请自行核对来源。

## 配置与排障

1. 打开应用顶部的 **“技能”** 页面。
2. 在需要的技能卡片上选择安装或配置。
3. 填写服务 URL 和 API Key，保存后确认状态变为已配置。
4. 若失败，使用关联的 **“导出本次诊断”**；不要通过复制凭据文件来排障。

有关 Key 的本地保存和运行期边界，请阅读 [安全与数据说明](SECURITY.md)。
