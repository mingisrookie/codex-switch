# ChatGPT Switch 安全与数据说明

## 目的

本文说明 ChatGPT Switch 会处理哪些本地数据、不会处理哪些数据，以及使用 API 模式前需要了解的边界。它不是对第三方 API 服务的安全背书。

## 官方登录

- 工具会读取并验证 ChatGPT Desktop 的官方登录状态，以确认可以安全切换。
- 工具不会替换、写回或删除官方登录文件，也不会让你主动退出官方账号。
- 官方账号本身仍由 ChatGPT Desktop 和 OpenAI 的正常登录、刷新与安全机制管理。

## API Key 与本地配置

- 保存 API 模式时，API Key 会使用当前 Windows 用户的 DPAPI 加密保存；界面不会回填或展示已保存 Key。
- API 模式运行期间，ChatGPT Desktop 需要能读取该凭据。当前实现会把 bearer token 写入本机受管 `config.toml` 的 API 模式配置中，因此它会以明文存在于当前 Windows 用户可读的运行配置内。
- 切回官方模式时，工具会删除该受管 API 模式配置及其中的 bearer token。
- 不要把 `config.toml`、诊断包、屏幕截图或日志未经检查地发给他人；也不要将它们提交到公开 Issue。

这项运行期明文边界无法仅靠“加密保存”抵消。请使用受信任的 Windows 用户账户，限制其他用户读取你的本地配置，并在不需要 API 模式时切回官方模式。

## 本机会话、备份与恢复

- 模式切换会改动受管请求配置。
- 会话迁移、合并与修复、恢复可见、完整备份、恢复备份和删除恢复点，都是由你在界面中明确发起的本地操作。
- 会话遇到冲突或无法可靠判断时，工具以保留原内容为优先，不会直接猜测覆盖。
- 完整备份是本地恢复点，不是云备份；请自己决定备份保存位置、Windows 权限和保留期限。
- 恢复和迁移可能改动本地会话与数据库视图。执行前应创建完整备份，并确保相关程序按界面要求关闭。

## 网络与第三方 API

- ChatGPT Switch 不是 API 服务商，不转售账号、API Key、模型额度或请求。
- 工具不会主动把已有历史聊天批量上传到服务端。
- 当 API 模式启用时，你新发出的请求会发送给你配置的 API 服务。该服务可能记录请求、内容、IP、用量或其他元数据；请自行阅读其隐私政策、数据保留规则、费用和合规条款。
- 只有使用你有权使用且信任的 API 服务，才应启用 API 模式。

## 诊断导出

诊断导出面向排障，包含经过脱敏的操作与健康信息。设计目标是不包含 API Key、登录 token、聊天正文、请求正文和响应正文，但没有任何自动脱敏能替代人工复核。

向维护者报告问题时：

1. 先删除或遮盖账号、路径、URL、Key、token 和聊天内容。
2. 仅提供重现所需的最小信息。
3. 不要把完整 `config.toml`、`auth.json`、会话文件或备份上传到公开 Issue。

## 可选技能

Image2 和 Grok 搜索是独立的可选功能。它们的服务 URL 和 API Key 与核心模式切换分开管理；不安装它们不会影响官方模式或 API 模式。详见 [可选技能说明](SKILLS.md)。

## 已知边界

- 仅支持 Windows x64，依赖当前 Windows 用户的 DPAPI。
- 它不能阻止拥有同一 Windows 用户权限的恶意程序读取运行期间的本地文件。
- 它不能保证第三方 API 服务的可用性、隐私或计费正确。
- 它不能替代你自己的完整备份、终端防护、磁盘加密、账号安全和密钥轮换策略。

如需理解实现层面的请求切换、会话、备份和更新流程，请阅读 [完整运行链路](../项目完整链路说明.md)。
