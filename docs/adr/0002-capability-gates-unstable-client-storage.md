# ADR 0002：以能力门禁隔离不稳定客户端存储

- 状态：Accepted
- 日期：2026-09-04

## 决策

ChatGPT/Codex 包版本只作为诊断信息；写入授权由当前 SQLite 文件身份、完整性、表列和 Schema 指纹决定。请求配置、会话视图和高级存储分别建模，未知结构只阻止依赖它的能力。

## 原因

本地 SQLite 和进程结构不是本项目控制的稳定公共接口。按版本猜兼容会产生误判；把所有功能绑在同一个总开关又会不必要地阻断 fresh-home 请求路由。

## 后果

高级存储成为显式高级域；未知结构保留只读扫描和诊断。每次高风险写操作仍在 mutation lock 内重新检查 writer 和文件状态。
